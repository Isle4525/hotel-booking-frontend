# 🏨 Booker — Платформа бронирования отелей

Современное SPA-приложение на **React 19** и **Vite** для поиска и бронирования номеров в премиальных отелях Казахстана с интерактивной фильтрацией, корзиной заказов и автоматическим калькулятором цен в реальном времени.

## 🏗 Архитектура проекта

Проект построен по компонентно-ориентированному принципу с однонаправленным потоком данных (Unidirectional Data Flow):

```
       [ App.jsx ]  <--- Хранит глобальное состояние корзины (cartItems, isCartOpen, toast)
       /    |    \
      /     |     \
[Header]  [Hero]  [HotelList]  ---> [HotelCard]
      \     |     /
       \    |    /
     [BookingCart]  <--- Выдвижная панель: калькулятор, скидки, оформление
```

- **`App.jsx`** — корневой контейнер приложения. Управляет состоянием корзины (`cartItems`), открытием панели (`isCartOpen`), плавающим виджетом быстрого доступа и всплывающими Toast-уведомлениями.
- **`Header.jsx`** — навигационная панель с логотипом, ссылками на секции и кнопкой корзины со счетчиком выбранных номеров.
- **`Hero.jsx`** — главный промо-баннер с формой быстрого перехода к каталогу.
- **`HotelList.jsx`** — каталог отелей с динамической фильтрацией по категориям, статистикой и модальным окном подробной информации.
- **`HotelCard.jsx`** — карточка отеля с бейджами, рейтингом, удобствами, индикатором уже добавленных номеров и кнопками действий.
- **`BookingCart.jsx`** — компонент корзины и умного калькулятора стоимости номеров.
- **`Services.jsx`** и **`Footer.jsx`** — информационные секции преимуществ и подвала.

## 🎨 Организация стилей (CSS Architecture)

Все стили проекта вынесены в отдельную директорию **`src/styles/`**, что полностью избавляет папку компонентов от визуального шума и дублирования файлов:

1. **`src/styles/index.css` (Глобальный слой)**:
   - Дизайн-токены (`:root` переменные: основные цвета, тени, радиусы, шрифты, переходы);
   - CSS Reset и базовые стили тегов (`body`, `html`, `#root`);
   - Общие раскладки секций (`.section`, `.section-header`, `.section-title` и т.д.);
   - Базовые стили кнопок (`.btn-primary`, `.btn-secondary`, `.btn-book`, `.btn-add-cart`);
   - Глобальные CSS-анимации (`fadeIn`, `slideUp`).

2. **Стили компонентов (`src/styles/*.css`)**:
   Каждый компонент имеет отдельный файл стилей в папке `src/styles/`:
   - **`Header.css`** — шапка, адаптивное меню, счетчик корзины;
   - **`Hero.css`** — промо-блок, фоновый градиент, поисковая форма;
   - **`HotelList.css`** — тулбар фильтров, кнопки категорий, сетка отелей и модальные окна;
   - **`HotelCard.css`** — оформление карточки, зум картинок, бейджи, цены и кнопки действий;
   - **`Services.css`** — сетка преимуществ и иконки;
   - **`Footer.css`** — колонки подвала и адаптивная верстка;
   - **`BookingCart.css`** — выдвижная панель корзины, степперы количества, чекбоксы опций, расчет скидок, форма чекаута и ваучер.

3. **`src/styles/App.css` (Слой приложения)**:
   - Обертка `.App`;
   - Плавающий виджет быстрого доступа (`.floating-cart-bar`);
   - Всплывающие уведомления (`.app-toast`).

> **Преимущество:** В папке `src/components/` хранятся только чистые React-компоненты (`.jsx`), а все стили собраны в `src/styles/`. Это обеспечивает идеальный порядок и прозрачную структуру.

## 🚀 Ключевой функционал

### 1. Каталог и фильтрация по кнопкам
- Реализована динамическая фильтрация массива отелей по категориям (`Luxury Hotel`, `Mountain & Ski`, `Business Hotel`, `Resort & Beach` и др.).
- Категории вычисляются автоматически из данных через `new Set()`.
- Клик по кнопке категории фильтрует список. Повторный клик по активной кнопке возвращает к показу всех отелей (`All`).
- Строка статуса отображает точное количество найденных отелей и кнопку быстрого сброса.

### 2. Карточки отелей
- Отображение фото, бейджа (Popular, Top Rated и др.), категории, города, рейтинга и удобств.
- **Кнопка «Details»** — открывает модальное окно с описанием и удобствами.
- **Кнопка «+ Add Room»** — добавляет 1 номер в корзину с показом интерактивного Toast-уведомления.
- **Кнопка «Book Now»** — сразу открывает панель корзины с калькулятором.
- **Зеленый бейдж `✓ In cart: X rooms`** — показывает статус, если номер уже добавлен.

### 3. Корзина и автокалькулятор (`BookingCart`)
- **Мультибронирование**: бронирование нескольких номеров одного или разных отелей одновременно.
- **Интерактивные счетчики (Степперы)**:
  - Количество номеров (от 1 до 10);
  - Количество ночей (от 1 до 30);
  - Количество гостей на номер (от 1 до 6).
- **Дополнительные услуги (мгновенный пересчет)**:
  - ☕ Завтрак "шведский стол" (+3 500 ₸ / номер / ночь);
  - 🧖 Спа & Wellness абонемент (+5 000 ₸ / номер);
  - 🚗 VIP-трансфер из аэропорта (+7 000 ₸).
- **Автоматическая система скидок**:
  - Оптовая скидка: при заказе 2+ номеров начисляется **5%**, при 4+ номерах — **10%**!
  - Промокоды: поле ввода промокодов (поддерживаются, например, `WELCOME10`, `PROMO15`, `SPRING5`).
- **Сводка расчета (`Total Price Breakdown`)**:
  - Базовая стоимость проживания;
  - Дополнительные услуги;
  - Примененная скидка;
  - Налоги и сборы (включены);
  - Итоговая сумма к оплате в тенге (`₸`).
- **Чекаут и ваучер бронирования**:
  - Ввод данных гостя (ФИО, телефон, e-mail, пожелания);
  - Выбор способа оплаты (при заселении, картой онлайн или Kaspi QR);
  - Экран подтверждения с генерацией номера ваучера (например, `#BK-481920`) и детализацией.

### 4. Глобальное состояние и виджеты
- **Header Cart Badge**: отображает суммарное число номеров в корзине.
- **Floating Cart Bar**: плавающая плашка в правом нижнем углу экрана, информирующая о сумме и количестве номеров с возможностью открыть калькулятор в 1 клик.
- **Toast Notifications**: ненавязчивые всплывающие подсказки при добавлении или удалении позиций.

## 💻 Запуск и сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm run dev
```
Сервер запустится по адресу [http://localhost:5173](http://localhost:5173).

### Проверка линтером (Oxlint):
```bash
npm run lint
```

### Сборка для продакшена:
```bash
npm run build
```
Готовые оптимизированные файлы появятся в папке `dist/`.

1. **Подключение реального бэкенда**:
   - Заменить статический массив `hotelsData` на запрос к REST API / GraphQL (например, `fetch('/api/hotels')`).

   - Связать поля выбора дат заезда/выезда из `Hero.jsx` с корзиной, чтобы количество ночей рассчитывалось автоматически по разнице дат.
3. **Сохранение корзины в `localStorage`**:
   - Добавить сохранение массива `cartItems` в `localStorage`, чтобы при перезагрузке страницы выбранные номера не пропадали.
